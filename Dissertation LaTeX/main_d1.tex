    \subsection{Skin Lesion Classification Models} \label{lit:models} % NEEDS REWRITE
    using ML has greatly improved early detection of skin lesions...


    What is a skin lesion classification model?
    \\
    Type of Machine Learning model trained to identify lesion areas in images of skin areas \cite{tess_pi,jesmdt_2025}.
    \\
    Choosing an appropriate pre-existing model or training my own will determine the baseline performance I will evaluate against later on.
    \\[1\baselineskip]

    % verify dataset details later
    Top datasets:\\
    Ham10000 - contains 10,015 dermoscopic (medical, of skin area) images categorised for 7 different classes of skin lesion. Used as a standardised benchmark for multi-class skin lesion classification because data is verified to very high standard \cite{survey_2023}.
    \\
    ISIC Archive and Challenge - multiple releases of thousands of curated dermoscopic images. Used as a standardised competition benchmarks with split training/validation/test sets and evaluation protocols \cite{survey_2023}.
    \\
    PH2 - small set containing 200 dermoscopic images with 3 different classes. Used because includes expert manual verification.

    Existing models:
    Multi-modal approach on an FPGA which combines image features with patient metadata \cite{jesmdt_2025}. Uses MobileNetV2 architecture.
    \\[1\baselineskip]

    Architectures:
    \\
    Fundamental MobileNet paper with X features \cite{mobilenet_2017}.
